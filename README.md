# 라이딩스타 라디오 시나리오

라디오 방송 회차별 시나리오와 큐시트를 웹페이지에서 확인하고 인쇄할 수 있도록 관리하는 정적 페이지입니다.

## 현재 메인 회차

- 방송일시: 미정
- 녹음일시·장소: 미정
- 프로그램: 라이딩스타
- 진행자: 박정규, 강왕규
- 출연: 카페에서 근무하며 자전거로 출퇴근하는 게스트(이름 미정)
- 주제: 새벽을 달리는 사람 · 커피향보다 먼저 출발하는 자전거
- 예상 러닝타임: 60분
- 원고 상태: 초안 · 음악 4곡 미정

## 회차 파일

- `index.html`: 새벽을 달리는 사람 · 생활 속 자전거 출퇴근 웹페이지
- `student-bike-app.html`: 대학생 4인 · 자전거 앱과 탄소감축 웹페이지(기존 대본·이미지 자료 보존)
- `velo-hyeoksin.html`: 벨로혁신 · 두 바퀴로 이어지는 사람들 웹페이지
- `kim-mikyung.html`: 김미경 · 자전거와 운동이야기 웹페이지
- `tangamja.html`: 김길중 · 탄감자와 자전거 챌린지 이야기 웹페이지
- `dubase.html`: 두바세 · 춘천 자전거 모임 이야기 웹페이지
- `episodes/dawn-commuter.md`: 새벽 출퇴근 게스트 편의 대본·큐시트·질문·확인 사항
- `episodes/2026-10-19-student-bike-app.md`: 대학생 4인 자전거앱 프로젝트 특집
- `episodes/2026-08-velo-hyeoksin.md`: 벨로혁신, 두 바퀴로 이어지는 사람들
- `episodes/2026-06-15-tangamja.md`: 탄감자와 자전거 챌린지 이야기
- `episodes/2026-06-05-riding-star.md`: 자전거와 운동이야기
- `episodes/dubase.md`: 두바세를 만나다

## 화면 사용

- 좌측 회차 관리 메뉴에서 게스트 이름을 클릭하면 오른쪽 화면이 해당 회차로 전환됩니다.
- 오른쪽 상단 탭에서 선택된 회차의 큐시트, 전체 대본, 질문 카드, 진행표, 확인 항목을 따로 확인합니다.
- 대학생 4인 회차의 '확인' 다음에는 '이미지 자료' 탭이 있습니다. 첨부 이미지 10장을 파일명 숫자 순서대로 보고 관련 질문을 확인할 수 있습니다.
- 이미지 자료에서 이전/다음 이동, 썸네일 선택, 확대, 원본 크기 보기, 개별 원본 다운로드를 지원합니다.
- 추가 질문·메모는 이미지별로 현재 브라우저의 로컬 저장소에 자동 저장됩니다. 브라우저·사이트 주소가 바뀌거나 저장소를 지우면 공유·유지되지 않으며, 저장 불가 시 화면에 표시됩니다.
- 원본 이미지는 `assets/student-bike-app/1.png`부터 `10.png`까지 보관합니다. 이미지의 수치와 기능은 참고 예시로, 실제 구현 및 검증 여부는 게스트에게 확인합니다.

## 이미지 메뉴 검증

- `tests/image-gallery.test.cjs`는 Node.js 기본 테스트 러너와 jsdom 26.1.0을 사용합니다.
- jsdom을 별도 테스트 디렉터리에 설치한 경우 해당 `node_modules`를 `NODE_PATH`로 지정한 뒤 `node --test tests/image-gallery.test.cjs`로 실행합니다.
- 이미지 파일·순서, 질문, 메모 저장과 실패 처리, 확대 상태, 회차 이동과 뒤로 가기를 검사합니다. 실제 레이아웃과 브라우저의 기본 모달 동작은 별도 화면 확인이 필요합니다.

## 자료 메모

- 현재 회차는 사용자 제공 `붙여넣은 텍스트.txt`의 ‘새벽을 달리는 사람’ 원고를 기준으로 반영했습니다.
- 진행자 호칭은 대사 안의 소개와 끝인사까지 박정규·강왕규로 통일했습니다. 이름이 미정인 출연자는 ‘게스트’ 또는 ‘게스트님’으로 표기했습니다.
- 원고의 발화 109개, 음악 4곡을 포함한 60분 진행표, 정리한 질문 30개와 사전 확인 사항을 반영했습니다.
- 근무 매장명, 정확한 근무시간·출퇴근 경로·거주지 공개는 게스트 동의 후 진행합니다.
- 대학생 편의 2026-10-19 방송 정보와 대본, 질문 19개, 이미지 자료 10장은 별도 회차로 유지했습니다.
